# 标擎 BidPilot 比赛验收指南

适用版本：v0.8.0
命题：超聚变“招投标信息聚合工具”
建议验收环境：Windows 10/11、macOS 或 Linux，Python 3.11+

## 1. 五分钟快速验收

### 1.1 安装

```text
python bootstrap.py --dev
```

需要验证网页登录来源时，追加安装浏览器组件：

```text
python bootstrap.py --auth
```

### 1.2 启动

Windows：

```text
.venv\Scripts\python.exe -m bidpilot serve
```

macOS/Linux：

```text
.venv/bin/python -m bidpilot serve
```

打开 `http://127.0.0.1:8000`。页面应显示“系统在线”“10 真实来源”“0 硬编码结果”“100% 可回溯”。

### 1.3 验证自然语言解析

输入：

```text
最近3个月上海充电桩招标信息，请每天9:00汇总后发送给我
```

点击“预览检索口径”，应确认：主题为充电桩、地域为上海、时间范围为近 3 个月、计划为每日 09:00。预览不会立即创建订阅；确认后才执行。

### 1.4 验证即时查询和 Word

输入：

```text
最近一年广东省服务器招标信息
```

选择“报告中心”，启动任务。完成后检查：

1. 结果页展示来源扫描→候选→保留漏斗和逐来源诊断。
2. 每条结果包含标题、发布时间、来源、原文 URL、事实摘要和附件（原文存在时）。
3. Word 报告出现 `.docx`，文件名符合“用户问题_时间.docx”。
4. Word 中保留查询口径、来源覆盖和真实原文链接。

## 2. 登录来源验收

### 2.1 中国招标投标网

1. 进入“来源状态”，找到“中国招标投标网”。
2. 点击“打开浏览器授权”，在服务主机弹出的 Chromium 中由用户本人登录。
3. 回到来源状态点击“我已登录，完成授权”。
4. 系统自动执行真实搜索与免费会员详情验证。
5. 只有读取到账号原本可见的免费会员详情时，状态才变为“授权已验证可用”。

验收失败条件：仅检测到任意 Cookie 即显示成功；失败/过期会话仍显示增强；Cookie 出现在 API、日志或仓库。

### 2.2 千里马免费会员有界列表

1. 在“千里马招标网”卡片点击“在系统内免费登录”。
2. 在服务主机弹出的独立 Chromium 中由用户本人扫码或输入账号。
3. 进入会员搜索页、看到“会员中心”后，回到来源状态点击“我已登录，完成授权”。
4. BidPilot 保留同一个持久 profile，并执行一次“服务器”有界列表验证。桌面环境为可见浏览器；Linux 后台只有在已完成可见登录后，才可用同一 profile 做有界无头检索。
5. 通过后状态为“授权已验证可用”；立即执行普通查询时，千里马只提交一个主题，默认最多读取 2 页/40 条，并受 30 秒冷却与每日 24 次预算限制。
6. 会员监控默认关闭；只有同时配置书面授权或官方 API 的记录编号时才允许开启。验收不得用开关替代授权材料。

边界验证：

- 关闭或重启服务后，如果原站要求重新登录，应返回 `auth_required`，不能冒充成功。
- 每日/每周/月度/未来一次任务不得使用千里马会员浏览器，只能使用公开分类流。
- 不应出现自动翻页、详情点击、附件下载或付费内容读取。
- `data/browser_profiles/qianlima/` 和授权数据库不得进入源码压缩包或 Git。
- 点击“清除”后，本机浏览器配置目录应删除。

## 3. 多来源、过滤与去重验收

1. 在来源状态应看到 10 个真实适配器及其接入模式。
2. 任一来源失败时，本轮仍应保留其他来源结果，并明确披露失败。
3. 选择有时间、地域、公告类型和排除词的问题；被排除项应进入诊断计数。
4. 同一公告的跨站转载应聚合来源 URL，不重复生成多条机会。
5. 同一项目的招标、更正、中标和合同应进入生命周期，而不是互相覆盖。

## 4. 零结果验收

输入一个窄问题，例如：

```text
最近一年物业小区劳务购买服务招标信息
```

即使最终为 0 条，系统仍应生成诊断 Word，展示总扫描数、候选数、保留数、逐项排除原因、来源覆盖缺口和安全放宽建议；不得生成虚构公告。

## 5. 长期任务与增量验收

1. 创建每日或每周订阅，确认 `next_run_at`。
2. 点击“立即执行”，记录运行与投递历史。
3. 对同一内容再次执行，已成功目标不应重复收到同一公告版本。
4. 暂停后不再自动执行；恢复后重新计算时间。
5. 重启服务，订阅 ID、启用状态、计划、历史和投递账本仍存在。
6. 模拟一个目标失败、另一个成功；恢复时只重试失败目标。

## 6. AI 深度与证据验收

- 规则高置信时应明确显示无需调用模型。
- 模型未配置、超时或返回非法 JSON 时，应回退本地规则，不阻塞任务。
- 模型不得改变日期、地域、公告类型和排除词硬边界。
- 语义复核必须引用候选中逐字存在的片段，否则拒绝。
- 情报简报、企业适配和证据追问中的标题、采购人、日期、地域和 URL 必须从本地固定证据回填。

## 7. API、CLI 和配置验收

```text
.venv\Scripts\python.exe -m bidpilot parse "最近1个月江苏服务器招标信息"
.venv\Scripts\python.exe -m bidpilot run "最近1个月江苏服务器招标信息"
.venv\Scripts\python.exe -m bidpilot status
.venv\Scripts\python.exe -m bidpilot sources
.venv\Scripts\python.exe -m bidpilot openapi
```

打开 `/docs`，确认 52 个操作均有中文用途、参数、返回、副作用、错误和示例。配置 API 读取时只显示密钥“已配置/未配置”，不能返回明文。

## 8. 工程门禁

Windows：

```text
.venv\Scripts\python.exe -m pytest
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
.venv\Scripts\python.exe -m compileall -q bidpilot tests tools
node --check bidpilot\static\app.js
git diff --check
```

还应验证 JSON、YAML、TOML 可解析，源码压缩包不含 `.env`、数据库、密钥、Cookie、浏览器配置、缓存和生成报告。
