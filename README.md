# 标擎 BidPilot

标擎 BidPilot 是一个证据优先的招投标情报 Agent，为 2026 AI 先锋未来人才大赛超聚变命题打造。

它把自然语言编译成可审计的检索与订阅任务，从多个招投标网站获取信息，完成清洗、筛选、跨站去重、项目生命周期关联和证据约束摘要，并生成 Word 报告。带频率的查询会被保存为定时订阅，后续只投递未送达的新版本。

> 当前仓库正在按 [SPEC.md](SPEC.md) 与 [sprint_contract.md](sprint_contract.md) 实现。完整安装、运行和演示说明将在核心流程通过端到端验证后补充。

## 合规原则

- 仅访问公开信息或用户主动授权的免费会员可见信息。
- 不绕过验证码、付费墙和访问控制。
- 每条摘要保留原始链接与证据片段；覆盖不完整时明确披露。
- 登录态和 API 密钥仅保存在本机，不进入 Git。
